# UI

## Overview
Implements the AppKit desktop control interface for connected iPhones, including window lifecycle coordination (`ControlWindowCoordinator`, `ControlWindowController`), live video rendering and Bluetooth HID mouse/keyboard steering (`PhoneControlView`), hardware/system shortcut sidebar (`ControlSidebar`), connection status overlay (`ControlConnectionOverlay`), lock-screen banner (`ControlLockNotice`), and coordinate/keyboard mapping models (`ControlInput`).

## Interface
- `[ControlConnectionOverlay.swift:ControlConnectionStatus]` — Connection state enum (`waitingForDevice`, `disconnected`, `unmatched`, `connecting`, `verifyingScreen`, `connected`) with `showsOverlay: Bool` (`[ControlConnectionOverlay.swift:ControlConnectionStatus.showsOverlay]`) and `resolve(hasScreen:hasMatchedHost:bluetoothState:inputIsCurrent:inputIsReady:screenPermitsInput:)` (`[ControlConnectionOverlay.swift:ControlConnectionStatus.resolve(hasScreen:hasMatchedHost:bluetoothState:inputIsCurrent:inputIsReady:screenPermitsInput:)]`).
- `[ControlConnectionOverlay.swift:ControlConnectionOverlay]` — `NSView` overlay displaying pairing/connection instructions and view-only/reconnect controls (`isDismissed`, `setDismissed(_:)`, `update(_:)`, `refreshLocalization()`).
- `[ControlInput.swift:ControlImageLayout]` — Aspect-fit video frame geometry calculator (`imageRect: CGRect`, `init?(screenSize:bounds:)`, `normalizedPoint(_:clamp:) -> CGPoint?`).
- `[ControlInput.swift:ControlMousePosition]` — Pending mouse coordinate tracker (`update(_:)`, `takePosition() -> CGPoint?`, `markSubmitted(_:)`, `reset()`).
- `[ControlInput.swift:ControlKeyboardCommand]` — Keyboard action enum (`.key(String, modifiers: [String])`, `.text(String, modifiers: [String])`).
- `[ControlInput.swift:ControlKeyboardEvent]` — `NSEvent` keyboard wrapper (`keyCode`, `modifierFlags`, `characters`, `charactersIgnoringModifiers`, `init(_:)`, `init(keyCode:modifierFlags:characters:charactersIgnoringModifiers:)`, `isPasteShortcut`, `static func isPasteShortcut(_:)`, `command: ControlKeyboardCommand?`).
- `[ControlLockNotice.swift:ControlLockNotice]` — Non-interactive lock-state notice banner (`init(frame:)`, `refreshLocalization()`, `update(_:)`, `hitTest(_:)`).
- `[ControlSidebar.swift:ControlSidebar]` — `NSView` vertical shortcut bar (`static let width: CGFloat = 116`, `onAction: ((ControlShortcut) -> Void)?`, `update(available:status:)`, `refreshLocalization()`).
- `[ControlSidebar.swift:ControlShortcut]` — Hardware/system shortcut enum (`home`, `search`, `paste`, `enter`, `volumeUp`, `volumeDown`, `power`) with `title`, `symbol`, `help`, `report: ReportID`, `isAvailable(on:) -> Bool`, and `perform(on:) throws`.
- `[ControlWindow.swift:ControlWindowUpdateReason]` — Window refresh reason enum (`discovery`, `userRequest`, `resumeDesktopMode`).
- `[ControlWindow.swift:ControlWindowState]` — Pure window-presentation state machine (`mode`, `deviceIDs`, `needsWaitingWindow`, `init(mode:)`, `setMode(_:)`, `update(connectedIDs:reopenClosed:)`, `update(connectedIDs:reason:canReplaceWaitingWindow:)`, `close(deviceID:) -> Bool`).
- `[ControlWindow.swift:ControlWindowCoordinator]` — Manages open `ControlWindowController` instances across connected devices (`init(modeStore:)`, `start()`, `stop()`, `showAllDevices()`).
- `[ControlWindow.swift:ControlWindowController]` — `NSWindowController` / `NSWindowDelegate` hosting `PhoneControlView` and `ControlSidebar` for a single device or waiting window (`deviceID`, `onClose`, `onDeminiaturize`, `init(deviceID:name:)`, `updateDevice(_:)`, `stop()`).
- `[PhoneControlView.swift:PhoneControlView]` — `NSView` rendering the live `CVPixelBuffer` stream and forwarding mouse/keyboard/shortcut events (`onShortcutStateChanged`, `onConnectionStateChanged`, `onLockStateChanged`, `init(deviceID:frame:)`, `start()`, `stop()`, `cancelInteraction()`, `performShortcut(_:)`).
- `[PhoneControlView.swift:ControlDeviceBinding]` — Generation-counted device/input binding state machine (`Connection`, `Request`, `deviceID`, `isRunning`, `generation`, `init(deviceID:)`, `start()`, `stop()`, `isCurrent(_:)`, `isDeviceBound`, `acceptsEvents(isKeyWindow:)`, `acceptsPointerSample(isTopmostWindow:isDragging:)`, `observe(_:)`, `beginInputRequest(at:)`, `finishInputRequest(_:host:session:isCurrentSession:)`).

## Invariants
- `[ControlConnectionOverlay.swift:ControlConnectionStatus.showsOverlay]` returns `true` if and only if status is neither `.connected` nor `.verifyingScreen`; `[ControlConnectionOverlay.swift:ControlConnectionOverlay.hitTest(_:)]` intercepts all mouse hits within bounds when visible and not dismissed, and passes hits through (`nil`) everywhere outside `pillView` when dismissed.
- `[ControlInput.swift:ControlImageLayout.init(screenSize:bounds:)]` returns `nil` if any dimension of `screenSize` or `bounds` is non-finite or `<= 0`; `[ControlInput.swift:ControlImageLayout.normalizedPoint(_:clamp:)]` flips bottom-left AppKit coordinates into top-left `[0, 1]` HID fractions and returns `nil` for points outside `imageRect` when `clamp == false`.
- `[ControlInput.swift:ControlKeyboardEvent.command]` maps special key codes to `.key` with all active modifiers, normalizes `Cmd+V` to `.key("v", modifiers: ["cmd"])`, and strips `"shift"` from `.text` modifiers when no `cmd`/`alt`/`ctrl` modifier is active because shift is already reflected in `characters`.
- `[ControlLockNotice.swift:ControlLockNotice.hitTest(_:)]` always returns `nil` so the lock banner never blocks mouse events.
- `[ControlWindow.swift:ControlWindowState]` keys window identity strictly by `deviceID` (never device name), keeps manually closed windows in `dismissedDeviceIDs` until reopened by `.userRequest`/`.resumeDesktopMode` or re-plugged in `.desktop` mode, and returns `true` from `close(deviceID:)` (triggering app termination) only when `mode == .desktop && deviceIDs.isEmpty`.
- `[PhoneControlView.swift:PhoneControlView.canSendWindowInput]` requires `binding.acceptsEvents(isKeyWindow: true)`, `connectionStatus == .connected`, and `input?.isBluetoothReady == true` for keyboard/shortcut events, whereas `[PhoneControlView.swift:PhoneControlView.canSendPointerInput]` allows pointer steering without key-window focus when `binding.acceptsPointerSample(isTopmostWindow:isDragging:)` holds.
- `[PhoneControlView.swift:PhoneControlView.refreshDevice]` and `[PhoneControlView.swift:PhoneControlView.resolveInput]` bind strictly by exact `device.id` and `ObjectIdentifier(device.screen)` (`===`), call `registry.match(allowProbing: false)` during background input resolution so background retries never move physical phone pointers, and cancel interactions whenever the connection or frame geometry changes (`[PhoneControlView.swift:PhoneControlView.setFrameSize]`).
- `[PhoneControlView.swift:ControlDeviceBinding.beginInputRequest]` allows at most one in-flight request and rate-limits attempts to at least `1` second since `lastInputAttempt`; `[PhoneControlView.swift:ControlDeviceBinding.finishInputRequest]` accepts a resolved `DeviceInput` only when `pendingRequest == request`, `isCurrent(request.generation)`, `connection == request.connection`, and `isCurrentSession == true`.

## Side Effects
- `[ControlConnectionOverlay.swift:ControlConnectionOverlay]` queries `IOBluetoothHostController.default()?.nameAsString()` on a background utility queue and triggers `DeviceRegistry.shared.reconnectBluetooth(resetExhausted: true)` when the reconnect button is clicked.
- `[ControlSidebar.swift:ControlShortcut.perform(on:)]` sends Bluetooth HID consumer reports (`0x0223`, `0x00E9`, `0x00EA`, `0x0030`) or keyboard shortcuts (`Cmd+Space`, `Cmd+V`, `Enter`) via `DeviceInput`.
- `[ControlWindow.swift:ControlWindowCoordinator]` registers a `NotificationCenter` observer for `AppRunModeStore.didChangeNotification`, runs a repeating `0.5` s `Timer` on `RunLoop.main` polling `DeviceRegistry.shared.all()` when not idle-suspended, creates/closes `ControlWindowController` windows, updates `QuietModeActivityController.shared.setOpenWindows(_:)`, and calls `NSApplication.shared.terminate(nil)` when the last window closes in `.desktop` mode.
- `[PhoneControlView.swift:PhoneControlView]` acquires and releases Bluetooth window demand on `HIDPeripheral.shared` (`beginWindowDemand`/`endWindowDemand`), runs a `30` Hz `Timer` on `RunLoop.main`, renders `CVPixelBuffer` frames via `VTCreateCGImageFromCVPixelBuffer` in `ControlScreenRenderer.draw`, preempts background pointer motion via `DeviceRegistry.shared.cancelBackgroundMotion`, and dispatches Bluetooth HID pointer/keyboard events via `DeviceInput`.
