# API

## Overview
Provides the localhost HTTP control server (`HTTPServer`), the browser-based live screen viewer (`WebPreview`), and the HTTP request router (`ControlAPI`) that dispatches device discovery, lease management, screen capture, OCR, Bluetooth HID pointer/keyboard actions, USB file/photo/app/log operations, dual-track accessibility routing, and multi-step Gemini agent tasks.

## Interface
- `[ControlAPI.swift:ControlAPI]` — HTTP router and request dispatcher namespace:
  - `[ControlAPI.swift:ControlAPI.normalizeRoutePath(_:)]` — Strips `/v1/leases/{lease}` and `/leases/{lease}` prefixes (ignoring reserved segments `acquire`, `wait`, `release`) and normalizes hyphenated/alias action subpaths (`/text` -> `/screentext`, `/double-tap` -> `/double_tap`, `/triple-tap` -> `/triple_tap`, `/hold-drag` -> `/hold_drag`, `/tap-icon` -> `/tap_icon`, `/scroll-until` -> `/scroll_until`, `/scroll-collect` -> `/scroll_collect`).
  - `[ControlAPI.swift:ControlAPI.handle(_:)]` and `[ControlAPI.swift:ControlAPI.handle(_:ocrCapture:ocrTap:activity:deviceCandidates:setupInputs:runtimeHooks:)]` — Primary and dependency-injected HTTP request dispatchers.
  - `[ControlAPI.swift:ControlAPI.shouldWakeScreen(normalizedPath:)]`, `[ControlAPI.swift:ControlAPI.shouldWakeControl(normalizedPath:)]`, and `[ControlAPI.swift:ControlAPI.WakeWindow]` (`deadline(wasSuspended:now:)`) — Classify routes that wake suspended screen capture or Bluetooth control in resident quiet mode and compute wake wait deadlines.
  - `[ControlAPI.swift:ControlAPI.waitUntilReady(deadline:now:sleep:ready:)]` — Polls `ready()` in up to 50 ms intervals until `deadline`.
  - `[ControlAPI.swift:ControlAPI.deviceSelector(body:query:)]` and `[ControlAPI.swift:ControlAPI.leaseSelector(body:query:)]` — Extracts `device`/`device_id` and `lease`/`lease_id` from request body or query string.
  - `[ControlAPI.swift:ControlAPI.runningExecutableMtime()]` — Returns the modification timestamp of the resolved executable binary.
  - Status, config, and setup routes: `[ControlAPI.swift:GET /]`, `[ControlAPI.swift:GET /status]`, `[ControlAPI.swift:GET /devices]`, `[ControlAPI.swift:GET /config]`, `[ControlAPI.swift:GET /viewer]`, `[ControlAPI.swift:GET /viewer/]`, `[ControlAPI.swift:GET /setup_status]`, `[ControlAPI.swift:GET /v1/setup/status]`.
  - Lease routes: `[ControlAPI.swift:POST /leases]`, `[ControlAPI.swift:POST /v1/leases]`, `[ControlAPI.swift:POST /leases/acquire]`, `[ControlAPI.swift:POST /leases/wait]`, `[ControlAPI.swift:POST /leases/release]`, `[ControlAPI.swift:DELETE /leases/{id}]`, `[ControlAPI.swift:DELETE /v1/leases/{id}]`.
  - Pairing and calibration routes: `[ControlAPI.swift:POST /match]`, `[ControlAPI.swift:POST /pair]`, `[ControlAPI.swift:POST /calibration/reload]`, `[ControlAPI.swift:POST /calibration/auto]`.
  - Screen capture, OCR, and recording routes: `[ControlAPI.swift:GET /screenshot]`, `[ControlAPI.swift:GET /ocr]`, `[ControlAPI.swift:POST /ocr]`, `[ControlAPI.swift:GET /screentext]`, `[ControlAPI.swift:POST /screentext]`, `[ControlAPI.swift:POST /recording/start]`, `[ControlAPI.swift:POST /record/start]`, `[ControlAPI.swift:POST /record_start]`, `[ControlAPI.swift:POST /recording/stop]`, `[ControlAPI.swift:POST /record/stop]`, `[ControlAPI.swift:POST /record_stop]`.
  - Input and batch action routes: `[ControlAPI.swift:POST /act]`, `[ControlAPI.swift:POST /tap_text]`, `[ControlAPI.swift:POST /tap_icon]`, `[ControlAPI.swift:POST /tap-icon]`, `[ControlAPI.swift:POST /scroll_until]`, `[ControlAPI.swift:POST /scroll-until]`, `[ControlAPI.swift:POST /scroll_collect]`, `[ControlAPI.swift:POST /scroll-collect]`, and `[ControlAPI.swift:Action]` routes (`/tap`, `/double_tap`, `/double-tap`, `/triple_tap`, `/triple-tap`, `/hold`, `/swipe`, `/hold_drag`, `/hold-drag`, `/scroll`, `/move`, `/nudge`, `/type`, `/key`, `/home`, `/power`, `/wake`, `/lock`, `/unlock`, `/mute`, `/unmute`).
  - USB, dual-track, and task routes in `[ControlAPI.swift:ControlAPI.handleUSBOrTaskRoute]`:
    - Photos: `GET /photos`, `POST /photos/list`, `POST /photo_list`, `GET /photos/content`, `GET /photos/pull`, `POST /photos/pull`, `POST /photo_pull`, `POST /photos/delete`, `POST /photo_delete`, `DELETE /photos`, `POST /photos/push`, `POST /photo_push`, `POST /photos`.
    - Files: `GET /files`, `POST /files/list`, `POST /file_list`, `GET /files/content`, `POST /files/pull`, `POST /file_pull`, `PUT /files/content`, `POST /files/content`, `POST /files/push`, `POST /file_push`, `DELETE /files`, `POST /files/remove`, `POST /file_remove`.
    - Apps & system: `GET /apps`, `POST /apps/list`, `POST /app_list`, `POST /open_app`, `POST /apps/open`, `GET /info`, `GET /device_info`, `POST /device_info`, `GET /logs`, `GET /device_logs`, `POST /device_logs`, `GET /assistive-touch`, `PUT /assistive-touch`, `POST /assistive-touch`, `GET /assistivetouch`, `POST /assistivetouch`.

    - Gemini agent tasks: `POST /task`, `POST /v1/tasks`.
- `[ControlAPI.swift:SwipeRequest]` — Validates and normalizes multi-point swipe paths (`points: [(Double, Double)]`, `duration: TimeInterval`, `init(_:screenSize:screenName:) throws`).
- `[ControlAPI.swift:RequestCoordinates]` — Converts pixel or `maxEdge`-scaled coordinates to `[0, 1]` screen fractions (`imageSize(_:maxWidth:maxEdge:)`, `point(_:_:_:screenSize:screenName:) throws`).
- `[ControlAPI.swift:OCRRequest]` — Parses and validates OCR options (`number(_:)`, `maxEdge(_:table:) throws`, `minConfidence(_:table:) throws`, `contentOnly(_:defaultValue:table:) throws`).
- `[ControlAPI.swift:TextTapRequest]` — Parses OCR text/icon tap parameters and resolves target pixels (`init(_:table:) throws`, `match(_:) throws`, `targetPixel(for:in:)`).
- `[ControlAPI.swift:ActRequest]` — Parses and executes up to 16 sequential action steps (`steps: [[String: Any]]`, `init(_:) throws`, `perform(device:capture:sleep:now:execute:) throws`).
- `[HTTPServer.swift:HTTPRequest]` — Parsed HTTP request (`method`, `path`, `query`, `body`, `static func parse(_:) -> HTTPRequest?`).
- `[HTTPServer.swift:HTTPResponse]` — Serialized HTTP response (`status`, `contentType`, `headers`, `body`, `static func json(_:status:)`, `static func error(_:status:)`, `var serialized: Data`).
- `[HTTPServer.swift:HTTPServer]` — Localhost TCP HTTP server (`init(port:handler:)`, `func start() throws`, `func stop()`).
- `[WebPreview.swift:WebPreview]` — HTML live preview generator (`static func response(for:) -> HTTPResponse`, `static func html(for:) -> String`).

## Invariants
- `[HTTPServer.swift:HTTPServer]` binds exclusively to `127.0.0.1` (`requiredLocalEndpoint = .hostPort(host: "127.0.0.1", port: port)`) with `allowLocalEndpointReuse = true`, processes one HTTP request per connection (`Connection: close`), and cancels connections whose receive buffer exceeds `8 << 20` bytes (8 MiB).
- `[HTTPServer.swift:HTTPRequest.parse]` returns `nil` until `\r\n\r\n` and at least `Content-Length` body bytes arrive; invalid or non-object JSON bodies parse as `[:]`, and duplicate query keys retain the last value.
- `[ControlAPI.swift:ControlAPI.handle(_:ocrCapture:ocrTap:activity:deviceCandidates:setupInputs:runtimeHooks:)]` treats `GET` requests with `wake=0` as passive (skipping `activity.requestStarted()` and `waitForWake`); body selectors override query parameters (`device` > `device_id`, `lease` > `lease_id`), and `leaseSelector` overrides `pathLease`.
- `[ControlAPI.swift:ControlAPI.resolveEffectiveDeviceQuery(_:leaseID:)]` prioritizes non-empty `deviceQuery` values other than case-insensitive `"default"` over the lease's bound `screenCaptureID`.
- `[ControlAPI.swift:ControlAPI.acquireOrWaitLease(body:deviceQuery:forceWaitRoute:deviceCandidates:)]` requires a non-empty `reason` string (`LeaseError.invalidReason`), requires `force` (if present) to be a strict `CFBoolean`, and forbids combining `force == true` with `forceWaitRoute` or `waitSeconds` (`LeaseError.forceAndWaitMutuallyExclusive`).
- `[ControlAPI.swift:ControlAPI.Action.requiresPointer]` requires pointer readiness only for `.tap`, `.doubleTap`, `.tripleTap`, `.hold`, `.swipe`, `.holdDrag`, `.scroll`, `.move`, and `.wake`; when enhanced track is inactive and `!input.isPointerReady`, `[ControlAPI.swift:ControlAPI.perform]` invalidates the pointer estimate and returns HTTP 503 before parsing action parameters.
- `[ControlAPI.swift:ControlAPI.perform]` authorizes the device lease before executing any action, forbids `key` equal to `"mute"` on `/key` (enforcing `/mute` or `/unmute` USB verification), and skips post-action stillness observation when `action == .lock`.
- `[ControlAPI.swift:ControlAPI.handleUSBOrTaskRoute]` rejects locked devices (`GhosthandError.deviceLocked`) for photo, file, app, and AssistiveTouch routes, while permitting locked devices on `/info` (`/device_info`) and `/logs` (`/device_logs`).
- `[ControlAPI.swift:ControlAPI.handleUSBOrTaskRoute]` enforces parameter bounds: photo list `limit` in `1...500` (default `50`), device logs `seconds` in `0.2...30.0` (default `2.0`) and `lines`/`max_lines`/`limit` in `1...2000` (default `200`), and list scroll `max_scrolls` in `1...50` and `end_after` in `1...10`.
- `[ControlAPI.swift:SwipeRequest.init]`, `[ControlAPI.swift:OCRRequest.number]`, and `[ControlAPI.swift:TextTapRequest.init]` reject bridged `CFBoolean` values where numeric values are expected and vice versa; `TextTapRequest.targetPixel` applies an upward Home-Screen icon offset `-max(24, Int((Double(result.height) * 0.042).rounded()))` when `icon == true && offsetY == 0` and clamps pixel coordinates to image bounds.
- `[ControlAPI.swift:ActRequest.init]` requires `1...16` steps, forbids nested `device`/`device_id` fields inside steps, limits per-step `delay`/`wait_text` to `0...6` seconds and total `waitBudget <= 30` seconds, and `[ControlAPI.swift:ActRequest.perform]` stops immediately without replay on the first non-200 response or thrown error.

## Side Effects
- `[HTTPServer.swift:HTTPServer.start]` and `[HTTPServer.swift:HTTPServer.stop]` start and cancel an `NWListener` on `127.0.0.1:port` over the concurrent dispatch queue `iphone-use.http`.
- `[ControlAPI.swift:ControlAPI.handle(_:ocrCapture:ocrTap:activity:deviceCandidates:setupInputs:runtimeHooks:)]` notifies `QuietModeActivityController` (`requestStarted`/`requestFinished`) and blocks in `waitForWake` polling `ScreenCaptureManager` and `DeviceRegistry` up to 6 seconds after wake.
- `[ControlAPI.swift:ControlAPI.acquireOrWaitLease]`, `[ControlAPI.swift:ControlAPI.authorizeDeviceLease]`, and `[ControlAPI.swift:ControlAPI.releaseLease]` mutate persistent lease records in `LeaseStore.current()` and enable AssistiveTouch via `StateDirUSBSystemProvider.shared.setAssistiveTouch(deviceID:enabled: true)` when live hardware is allowed.
- `[ControlAPI.swift:ControlAPI.perform]`, `[ControlAPI.swift:ControlAPI.tapTextPoint]`, and `[ControlAPI.swift:ControlAPI.screenshot]` cancel background pointer motion on `DeviceRegistry.shared`, send Bluetooth HID pointer/keyboard/consumer reports via `DeviceInput`, capture screen frames or hardware native screenshots, run Vision OCR (`ScreenOCR.recognize`), and poll `StillnessDetector` / `ListScrollWalker`.
- `[ControlAPI.swift:ControlAPI.handleRecordingStart]` and `[ControlAPI.swift:ControlAPI.handleRecordingStop]` start and stop video recording via `ScreenRecorderManager.shared` or `runtimeHooks.recorder`.
- `[ControlAPI.swift:ControlAPI.handleUSBOrTaskRoute]` performs USB AFC/house-arrest/syslog/app-launch operations via `USBSystemProviding`, reads and writes local files during photo/file pull and push, switches `DualTrackInputCoordinator` modes, queries live accessibility trees, and runs `GeminiTaskExecutor.run(options:hooks:store:)`.
- `[WebPreview.swift:WebPreview.html]` serves browser JavaScript that polls `/config`, `/devices`, and `/screenshot` and updates browser URL state via `history.replaceState`.
