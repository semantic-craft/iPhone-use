# MCP

## Overview
Implements the stdio Model Context Protocol (MCP) JSON-RPC server, 50-tool catalog and HTTP action translator, multi-step keyboard sequence validation, cross-process `flock` serialization, and automatic `--resident-quiet` background daemon launching.

## Interface
- `[MCPAccess.swift:MCPAccess]` — `enum MCPAccess` coordinating stdio MCP processes via `static func withService<T>(port: Int, language: AppLanguage = .en, _ body: () throws -> T) throws -> T` and `static func withDevice<T>(port: Int, id: String, language: AppLanguage = .en, _ body: () throws -> T) throws -> T`.
- `[MCPKeyboardSequence.swift:MCPKeyboardAction]` — `enum MCPKeyboardAction` with cases `.request(MCPToolRequest)` and `.delay(TimeInterval)`.
- `[MCPKeyboardSequence.swift:MCPKeyboardSequence]` — `enum MCPKeyboardSequence` providing `static let textOptions = TextEntry.textOptions`, `static let schema: [String: Any]`, `static func actions(arguments: [String: Any], language: AppLanguage = .en) throws -> [MCPKeyboardAction]`, and `static func isBoolean(_ value: Any?) -> Bool`.
- `[MCPServer.swift:MCPServer]` — `enum MCPServer` providing `static let longEdge = 1000`, `static var base: URL` (`http://127.0.0.1:7390`), `static var language: AppLanguage`, `struct DeviceListCache`, `struct MCPError: Error, CustomStringConvertible`, `static func run() -> Never`, `static func response(to message: [String: Any], callTool: (String, [String: Any]) -> [String: Any]) -> [String: Any]?`, `static func waitForStableFrame(sleep:now:frame:)`, `static func resolveDeviceCandidate(_ query: String?, data: Data) throws -> DeviceCandidate`, `static func resolveDevice(_ query: String?, data: Data) throws -> String`, `static func screenshotContent(image:device:width:height:includeImage:ocr:mimeType:includeScreentext:) -> [String: Any]`, and `static func executeToolCall(_ name: String, _ arguments: [String: Any]) -> [String: Any]`.
- `[MCPServiceLauncher.swift:MCPServiceLauncher]` — `enum MCPServiceLauncher` providing `typealias Spawner`, `nonisolated(unsafe) static var testSpawnerOverride: Spawner?`, `static func resolveExecutableURL(environment: [String: String] = ProcessInfo.processInfo.environment) -> URL?`, `@discardableResult static func ensureRunning(base:stateDirectory:executableURL:environment:timeout:pollInterval:probe:spawn:sleep:now:) -> Bool`, and `static func defaultSpawn(executable:arguments:environment:logURL:) throws`.
- `[MCPTools.swift:MCPToolCatalog]` — `enum MCPToolCatalog` providing `static func device(for table: StringsMCP) -> [String: Any]` and `static func tools(for language: AppLanguage) -> [[String: Any]]` defining 50 MCP tools: `list_devices`, `screenshot`, `ocr_screen`, `screentext`, `tap_text`, `move_pointer`, `adjust_pointer`, `click_pointer`, `tap`, `double_tap`, `triple_tap`, `hold`, `long_press`, `swipe`, `hold_drag`, `scroll`, `type_text`, `press_key`, `keyboard_sequence`, `home`, `wake`, `lock`, `unlock`, `mute`, `unmute`, `record_start`, `record_stop`, `act`, `setup_status`, `acquire`, `wait`, `release`, `photo_list`, `photo_pull`, `photo_delete`, `photo_push`, `file_list`, `file_pull`, `file_push`, `file_remove`, `app_list`, `open_app`, `device_info`, `device_logs`, `assistivetouch`, `task`, `switch_track_mode`, `get_track_status`, `get_ax_tree`, and `decide_track`.
- `[MCPTools.swift:MCPToolRequest]` — `struct MCPToolRequest` (`let path: String`, `let body: [String: Any]`) with `static func action(named name: String, arguments: [String: Any], longEdge: Int, language: AppLanguage = .en) throws -> MCPToolRequest?` translating MCP tool calls (and hyphen/underscore aliases `double-tap`, `triple-tap`, `hold-drag`, `recording_start`, `recording_stop`, `assistive_touch`, `track_status`, `ax_tree`) into HTTP API routes (`/act`, `/ocr`, `/screentext`, `/tap_text`, `/move`, `/nudge`, `/tap`, `/double_tap`, `/triple_tap`, `/hold`, `/swipe`, `/hold_drag`, `/scroll`, `/type`, `/key`, `/home`, `/wake`, `/lock`, `/unlock`, `/mute`, `/unmute`, `/recording/start`, `/recording/stop`, `/photos/list`, `/photos/pull`, `/photos/delete`, `/photos/push`, `/files/list`, `/files/pull`, `/files/push`, `/files/remove`, `/apps/list`, `/open_app`, `/device_info`, `/device_logs`, `/assistivetouch`, `/task`, `/track/switch`, `/track/status`, `/ax_tree`, `/track/decide`).

## Invariants
- `[MCPAccess.swift:MCPAccess.withLock]` — Requires any non-empty `IPHONE_USE_STATE_DIR` override to start with `/`; opens lock files with `O_CREAT | O_RDWR | O_CLOEXEC` (`0o600`), never unlinks them, and polls `flock(..., LOCK_NB)` every `0.05` seconds up to a `10`-second `systemUptime` deadline (`LOCK_SH` on `service-<port>.lock` in `withService`, `LOCK_EX` on `device-<port>-<hex_id>.lock` in `withDevice`).
- `[MCPKeyboardSequence.swift:MCPKeyboardSequence.actions]` — Restricts top-level keys to `["steps", "actions", "device", "device_id", "include_image", "observe"]`, requires `1...16` steps, requires `steps` and `actions` to be equal if both are passed, caps cumulative `text.count` across text steps to `<= 256`, requires valid `KeyboardMap` key codes and modifiers on key steps, and bounds delay steps to `0...5` seconds.
- `[MCPServer.swift:MCPServer.DeviceListCache.load]` — Reuses cached `/devices` data only when `self.origin == origin`, `now < expires` (`2` seconds TTL), and `fresh == false`.
- `[MCPServer.swift:MCPServer.call]` — Validates `observe` in `["full", "ocr_diff", "none"]` (default `"full"`) and strict CFBoolean `include_image` (default `true`); requires non-read-only tools (and any call supplying a `lease`) to pass `LeaseStore.current().authorizeAndTouch(deviceID: device, leaseID: leaseID, command: name)` inside `MCPAccess.withDevice` before issuing HTTP requests.
- `[MCPServer.swift:MCPServer.callAcquireOrWait]` — Requires non-empty trimmed `reason` and rejects combining `force == true` with wait mode (`LeaseError.forceAndWaitMutuallyExclusive`).
- `[MCPServer.swift:MCPServer.waitForStableFrame]` — Sleeps `0.15` seconds initially and bounds total frame stabilization polling to `< 0.6` seconds until two consecutive non-nil frame hashes match.
- `[MCPServiceLauncher.swift:MCPServiceLauncher.ensureRunning]` — Returns `false` immediately when `IPHONE_USE_AUTO_START` is `"0"`, `"false"`, or `"no"`; otherwise acquires `LOCK_EX` on `autostart-<port>.lock` and re-verifies `probe()` inside the lock before spawning `--resident-quiet`.
- `[MCPTools.swift:MCPToolCatalog.tool]` — Injects `device`, `device_id`, `lease`, and `include_image` into every tool schema, injects `observe` into non-`readOnly` tool schemas, bounds `act` steps to `1...16` items, bounds `adjust_pointer` `dx`/`dy` to `-32...32`, bounds `hold` durations to `100...10000` ms (`0.1...10.0` s), bounds `hold_drag` `holdMs` to `100...10000` ms and `durationMs` to `16...10000` ms, bounds `scroll` `ticks` to `1...1000`, `max_scrolls` to `1...50`, and `end_after` to `1...10`, requires printable US-ASCII (`0x20...0x7E`) for `unlock` `passcode`, rejects `press_key` with `"mute"` in favor of `mute`/`unmute`, and scales `normalized: true` coordinates from `0...1000` by dividing by `1000.0` with `fraction: true`.

## Side Effects
- `[MCPAccess.swift:MCPAccess.withLock]` — Creates the state directory (`$IPHONE_USE_STATE_DIR` or `~/Library/Logs/iPhoneUse`), opens/creates `service-<port>.lock` and `device-<port>-<hex_id>.lock`, acquires/releases `flock` locks, and sleeps the calling thread while polling.
- `[MCPServer.swift:MCPServer.run]` — Reads `IPHONE_USE_PORT` to configure `MCPServer.base`, reads JSON-RPC lines from `stdin`, writes JSON-RPC responses to `FileHandle.standardOutput`, and exits (`exit(0)`) on `stdin` EOF.
- `[MCPServer.swift:MCPServer.call]` — Acquires `MCPAccess` file locks, mutates `LeaseStore.current()` (`acquire`, `wait`, `release`, `authorizeAndTouch`), sends synchronous HTTP `GET`/`POST` requests to `MCPServer.base` via `URLSession.shared`, auto-starts the local service via `MCPServiceLauncher.ensureRunning` on connection failure when `allowAutoStart == true`, sleeps between multi-step actions, and computes OCR diffs via `ScreenOCR`.
- `[MCPServiceLauncher.swift:MCPServiceLauncher.ensureRunning]` — Acquires `autostart-<port>.lock`, creates/appends to `service-<port>.log`, and spawns the `iphone-use --resident-quiet` child `Process` with `IPHONE_USE_PORT` and `IPHONE_USE_STATE_DIR` set in the environment.
