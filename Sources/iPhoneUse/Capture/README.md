# Capture

## Overview

Manages USB screen capture, multi-device visual identity verification, dormant USB Valeria configuration switching and recovery, Vision-based OCR and lock-screen heuristics, and MP4 screen recording for connected iPhones.

## Interface

- `[CaptureAssociationIdentity.swift:CaptureAssociationIdentity]` - Retains confirmed UUID association identities per physical phone ID across AVFoundation capture source reroutes (`identity(physicalID:isConfirmed:)`, `retain(physicalIDs:)`).
- `[CaptureAssociationIdentity.swift:CaptureScreenMapping]` - Computes preview screen mappings (`Source`, `previews(confirmed:previous:sources:)`) preserving confirmed mappings and surviving capture source instances.
- `[CaptureIdentityMatcher.swift:CaptureIdentityImage]` - `24x40` RGB interior screen signature (`width = 24`, `height = 40`, `aspectRatio`, `pixels`, `init(aspectRatio:pixels:)`, `init?(image:)`, `isInformative`, `hasVisibleContent`, `distance(to:)`) cropping top/bottom 8% status/home-bar insets for USB screenshot comparison.
- `[CaptureIdentityMatcher.swift:CaptureIdentityMatcher]` - Pure matching algorithms (`verifiedMappings(physicalIDs:physical:sources:unavailable:)`, `match(physical:sources:)`) mapping physical USB device IDs to capture source IDs.
- `[CaptureIdentityVerifier.swift:ScreenCaptureIdentityState]` - Multi-device capture identity verification state enum (`.singleDevice`, `.pending`, `.verified`, `.partiallyVerified`, `.unavailable`, `.failed`) with `permitsAssociation(identityVerified:)`.
- `[CaptureIdentityVerifier.swift:CaptureIdentityRetrySchedule]` - Tracks active BLE session UUIDs per peripheral (`update(_:)`) to trigger identity re-verification once per new BLE session.
- `[CaptureIdentityVerifier.swift:CaptureIdentityVerifier]` - Bounded multi-attempt verifier (`Result`, `Screenshot`, `verify(physicalIDs:sourceImages:isCurrent:waitForRetry:screenshot:)`, `verify(physicalIDs:sourceImages:isCurrent:)`) comparing USB `screenshotr` images against live capture frames.
- `[CaptureValeriaRecovery.swift:CaptureSourceRecovery]` - Tracks one-shot recovery attempts per capture source instance UUID (`take(empty:)`, `retain(sources:)`).
- `[CaptureValeriaRecovery.swift:CaptureValeriaRecoverySnapshot]` - `Equatable` snapshot of manager lifecycle, topology, and identity state (`isMultiDevice`, `matchesTopologyAndGeneration(current:)`, `remainsValidForExecution(current:)`).
- `[CaptureValeriaRecovery.swift:CaptureValeriaRecoveryTracker]` - Bounded state machine (`maxUSBProbeAttempts = 2`, `maxRuntimeRestarts = 1`, `maxPassiveMultiDeviceRestoreChecks = 2`, `Entry`, `BeginDecision`, `FinishDecision`, `PendingEmptyDiscoverySwitch`, `RefreshSourceState`, `ScheduledPostSwitchCheck`, `RefreshReconciliation`) tracking per-source Valeria USB probes, session restarts, empty-discovery switches, and post-switch rollback timers.
- `[CaptureValeriaRecovery.swift:CaptureValeriaRecoverySource]` - Protocol abstracting a recoverable capture source (`id`, `instanceID`, `pinnedUSBDevice`, `isDeviceConnected`, `hasFrame`, `hasCaptureError`, `restart()`, `recordRecoveryError(_:)`).
- `[CaptureValeriaRecovery.swift:CaptureValeriaRecoveryHost]` - Protocol abstracting the capture manager hosting Valeria recovery (`recoveryLock`, `recoveryQueue`, lifecycle/topology/verification accessors, and multi-device gate callbacks).
- `[CaptureValeriaRecovery.swift:CaptureValeriaRecoveryCoordinator]` - Coordinator executing asynchronous USB Valeria activation, session restarts, pending-switch reconciliation, and gated USB restores (`schedulePostSwitchRestoreIfNeeded`, `applyRefreshPostSwitchChecks`, `reconcilePendingEmptyDiscoverySwitchIfNeeded`, `recoverEmptyDiscoveryIfNeeded`, `performGatedLiveRestore`, `recoverIfNeeded`).
- `[LockScreenRecognition.swift:DeviceLockState]` - Advisory lock-screen state enum (`.unknown`, `.notDetected`, `.suspected`, `.paused`) with `showsNotice`, `title`, and `message`.
- `[LockScreenRecognition.swift:LockScreenText]` - Struct holding recognized OCR text and top-left normalized `CGRect` bounds.
- `[LockScreenRecognition.swift:LockScreenRecognition]` - Vision OCR heuristic (`resemblesLockScreen(_:)`, `read(_:)`) detecting lock-screen clock/date/unlock patterns on a `CVPixelBuffer`.
- `[ScreenCapture.swift:ScreenCaptureStopResult]` - `Equatable` struct (`initiated`, `captureDrained`, `usbRestored`, `isClean`) reporting shutdown completion status.
- `[ScreenCapture.swift:StoppableCaptureSource]` - Protocol requiring `stop(completion:)` for coordinated source shutdown.
- `[ScreenCapture.swift:CaptureShutdownCoordinator]` - Coordinates bounded capture drain and USB configuration restoration under a single monotonic deadline (`stop(waitTimeout:activeSources:notifyQueue:restoreAllUSB:)`).
- `[ScreenCapture.swift:CaptureDiscoveryPinResolver]` - Resolves single-device IOKit USB physical pinning outside manager locks (`prequerySingleDevicePin`, `prequerySingleOpaqueDevicePin`).
- `[ScreenCapture.swift:CaptureStartupReconciliationGate]` - State machine (`.idle`, `.reconciling`, `.unresolved`, `.ready`) gating capture discovery until persisted same-boot USB switches are reconciled (`beginStart(generation:hasPendingSwitches:)`, `completeReconciliation(generation:clean:)`, `actionForPeriodicTick(generation:)`, `permitsCaptureDiscovery(generation:)`, `reset()`).
- `[ScreenCapture.swift:ScreenCaptureManager]` - Capture lifecycle and discovery manager (`shared`, `init(restoreAllUSB:)`, `onScreensChanged`, `start()`, `stop(waitTimeout:)`, `suspendForIdle(waitTimeout:observeUSBTopology:)`, `clearIdleUSBDemandIfUnplugged(observeUSBTopology:)`, `all`, `sampleScreensWithRevision()`, `mintUSBDemandRevision()`, `identityState`, `permitsPointerAssociation`, `permitsPointerAssociation(for:)`, `isCurrent(_:)`, `identityVerified(for:)`, `associationScreens`, `retryIdentityVerification()`).
- `[ScreenCapture.swift:ScreenCaptureSession]` - Public screen identity for a connected iPhone (`id`, `name`, `associationIdentity`, `sourceID`, `sourceInstanceID`, `size`, `captureError`, `frame()`, `observationFrame()`, `snapshot(png:maxWidth:maxEdge:)`, `thumbnail(width:height:)`).
- `[ScreenCapture.swift:ScreenCaptureFrameStore]` - Thread-safe store (`Snapshot`, `PublishOutcome`, `stop()`, `resume()`, `publishOutcome(_:receivedAt:)`, `publish(_:receivedAt:)`, `snapshot()`) for latest `CVPixelBuffer` frames.
- `[ScreenCapture.swift:CaptureRunningSession]` - Protocol abstracting `startRunning()` and `stopRunning()`, conformed to by `AVCaptureSession`.
- `[ScreenCapture.swift:CaptureSourceLifecycle]` - Serial-queue lifecycle coordinator for `CaptureRunningSession` and `ScreenCaptureFrameStore` (`isStopped`, `start()`, `restart(onBeforeStop:)`, `stop(onStopLocked:completion:)`, `stopAndWait(timeout:onStopLocked:)`).
- `[ScreenCapture.swift:CaptureSourceErrorTracker]` - Thread-safe error tracker preserving runtime and USB recovery errors across restarts until a subsequent frame is accepted (`lastError`, `hasError`, `currentRevision()`, `markStopped()`, `formatRuntimeError(_:)`, `recordRuntimeError(_:isStopped:)`, `recordRecoveryError(_:isStopped:)`, `clearOnAcceptedFrame(_:observedErrorRevisionBeforePublish:)`, `publishFrameClearingPriorErrors(_:into:receivedAt:beforeClearHook:)`).
- `[ScreenCapture.swift:ScreenCaptureSource]` - AVFoundation muxed capture wrapper (`AVCaptureVideoDataOutputSampleBufferDelegate`, `CaptureValeriaRecoverySource`, `StoppableCaptureSource`, nested `CaptureError`) providing frame access and PNG/JPEG snapshots.
- `[ScreenOCR.swift:ScreenOCR]` - Vision OCR engine, SHA-256 screen hashing, 8x8 stability signature, text diffing, and tiered text matching (`contentBandMinYFraction = 0.06`, `contentBandMaxYFraction = 0.92`, `Item`, `Result`, `Diff`, `decode(_:)`, `sorted(_:)`, `diff(device:current:)`, `summaryDiff(for:device:)`, `stabilitySignature(_:)`, `screenHash(_:)`, `recognize(_:device:recognition:)`, `formatNotFoundError(query:in:baseMessage:)`, `matchTiered(_:text:exact:index:oneBasedIndex:requireExplicitIndexWhenMultiple:)`).
- `[ScreenRecorder.swift:ScreenRecorderManager]` - Per-device screen recording manager (`shared`, `StopReason`, `Options`, `Status`, `Result`, `init(nowUptime:nowDate:)`, `start(deviceID:leaseID:isLocked:screenSize:options:frameProvider:)`, `stop(deviceID:stoppedBy:)`, `stopIfActive(forLease:stoppedBy:)`, `stopAllForDaemonShutdown()`).
- `[USBIdentityScreenshot.swift:USBIdentityScreenshot]` - Subprocess-isolated USB screenshot helper (`workerArgument`, `unavailableExitCode = 69`, `failedExitCode = 70`, `screenshotServiceIsUnavailable(_:)`, `capture(physicalID:)`, `run(executable:arguments:timeout:diagnostic:)`, `write(physicalID:output:)`) using MobileDevice's `com.apple.mobile.screenshotr` service.
- `[USBIdentityScreenshot.swift:DeviceLinkScreenshot]` - DeviceLink plist protocol exchange (`Failure`, `read(send:receive:)`) for `ScreenShotRequest` / `ScreenShotReply`.
- `[USBValeriaConfigurator.swift:USBValeriaConfigurator]` - Namespace managing detection, network-safety gating, activation, and restoration of dormant USB Valeria configurations (`NetworkCapability`, `ConfigurationDescriptorInfo`, `HostNetworkRouteSnapshot`, `ObservedBSDInterface`, `DeviceBSDNetworkState`, `DeviceCandidate`, `PinnedUSBDevice`, `ConnectedIOSUSBTopology`, `IOSUSBTopologyObservation`, `USBServicePropertyObservation`, `ActivatedSwitch`, `ActivationOutcome`, `RestoreOutcome`, `currentBootSessionUUID()`, `dormantValeriaConfiguration`, `dormantValeriaConfigurationValue`, `isOpaqueCaptureUUID(_:)`, `selectCandidateIndex`, `canSeizeExclusiveDevice`, `parseInterfaceClassesFromRawDescriptor`, `isVirtualTunnelOrLoopback(_:)`, `parseHostNetworkRoutes`, `classifyDeviceBSDInterfaces`, `permitsConfigurationSwitch`, `normalizedSerial(_:)`, `parseObservedUSBServiceProperties`, `observeIOSUSBTopology`, `currentIOSUSBTopology()`, `currentSingleIOSDeviceIdentity()`, `activateDormantValeriaConfiguration`, `requiresStartupReconciliation`, `hasTrackedSwitches`, `reconcilePersistedSwitchesAsync`, `restorePreviousConfiguration(registryEntryID:)`, `restorePreviousConfigurations(deadlineUptime:)`).
- `[USBValeriaConfigurator.swift:USBConfigDeviceSession]` - Protocol abstracting an IOKit USB device configuration session (`registryEntryID`, `getConfiguration()`, `openSafely()`, `close()`, `setConfiguration(_:)`).
- `[USBValeriaConfigurator.swift:USBSwitchLedger]` - Write-ahead per-boot-session USB configuration switch ledger (`LoadState`, `loadState`, `entries`, `requiresStartupReconciliation`, `reloadIfFaulted()`, `trackedEntryIDs`, `entry(for:)`, `markDeviceDetached(registryEntryID:)`, `activate(session:descriptors:allowPrimaryNetworkPreemption:inspectEnvironment:shouldProceed:)`, `restore(registryEntryID:session:)`).

## Invariants

- `[LockScreenRecognition.swift:DeviceLockState]` - Lock-screen OCR recognition is strictly advisory and must never block HID input or BLE pairing.
- `[CaptureIdentityMatcher.swift:CaptureIdentityMatcher.verifiedMappings]` - Direct visual identity matches require both images to be informative (`meanAbsoluteDeviation >= 6`), best RGB distance `<= 0.10`, second-best margin `>= 0.04`, and a unique target source; elimination matching is allowed for at most one `.unavailable` physical device when at least one direct match succeeded and the single remaining source `hasVisibleContent`.
- `[CaptureIdentityVerifier.swift:CaptureIdentityVerifier.verify]` - Runs at most 3 attempts, aborts with `.failed` if `isCurrent()` returns `false`, and requires two consecutive attempts with identical non-empty mappings before returning `.verified` or `.partiallyVerified`.
- `[ScreenCapture.swift:CaptureDiscoveryPinResolver.prequerySingleDevicePin]` - Single-device IOKit USB queries and `USBValeriaConfigurator` queue calls must execute strictly outside `ScreenCaptureManager.lock` so lock-order cycles between `ScreenCaptureManager.lock` and `USBValeriaConfigurator.queue` cannot occur.
- `[ScreenCapture.swift:CaptureStartupReconciliationGate]` - CoreMediaIO screen-capture property enablement (`kCMIOHardwarePropertyAllowScreenCaptureDevices`) and device discovery are blocked until persisted same-boot USB configuration switches from prior runs finish reconciling.
- `[ScreenCapture.swift:CaptureSourceLifecycle]` - Never holds `stateLock` across blocking `AVCaptureSession.startRunning()` or `stopRunning()` calls on the serial capture queue, and re-checks `stopped` immediately after `startRunning()` to stop if a concurrent teardown occurred.
- `[CaptureValeriaRecovery.swift:CaptureValeriaRecoveryTracker]` - Per source instance, USB Valeria activation probes are capped at `maxUSBProbeAttempts` (`2`), runtime-error session restarts at `maxRuntimeRestarts` (`1`), and passive multi-device post-switch restore checks at `maxPassiveMultiDeviceRestoreChecks` (`2`).
- `[ScreenOCR.swift:ScreenOCR.canReuse]` - Cached OCR results are reused only when every pixel's luma delta is `<= 16` and pixels with luma delta `> 6` do not exceed `1 / 2000` of total pixels against the original recognized reference frame.
- `[ScreenRecorder.swift:ScreenRecorderManager.start]` - Rejects recording when `isLocked == true` (`GhosthandError.deviceLocked`) or when `activeByDevice[deviceID]` is already present (`GhosthandError.recordingActive`), and validates `maxDurationSeconds` in `1...3600` and `fps` in `1...120`.
- `[USBValeriaConfigurator.swift:USBValeriaConfigurator.permitsConfigurationSwitch]` - Fails closed to protect active USB network tethering: unless `allowPrimaryNetworkPreemption` is true (or `IPHONE_USE_ALLOW_USB_TETHER_PREEMPTION=1`), switching away from a `.carriesNetwork` or `.unknown` configuration is denied whenever route/interface state is `.unknown`, a device BSD interface is active on a primary or unresolved route, or no confirmed non-device physical primary route exists.
- `[USBValeriaConfigurator.swift:USBSwitchLedger.activate]` - Enforces write-ahead persistence (`preSwitchIntent`) to disk before calling `session.setConfiguration(_:)`, refuses the hardware switch if persistence fails, and never overwrites an external third configuration during `restore(registryEntryID:session:)` (`.supersededByExternalChange`).

## Side Effects

- `[ScreenCapture.swift:ScreenCaptureManager.allowScreenCaptureDevices]` - Mutates process-wide CoreMediaIO state via `CMIOObjectSetPropertyData` (`kCMIOHardwarePropertyAllowScreenCaptureDevices = 1`) to expose muxed iOS capture devices.
- `[ScreenCapture.swift:ScreenCaptureManager.start]` - Requests video capture permission (`AVCaptureDevice.requestAccess(for: .video)`), schedules a 1s RunLoop timer, registers `NotificationCenter` observers for `AVCaptureDevice` connect/disconnect, and triggers asynchronous USB ledger reconciliation.
- `[ScreenCapture.swift:ScreenCaptureSource]` - Configures and runs `AVCaptureSession` with `AVCaptureDeviceInput` and `AVCaptureVideoDataOutput` on a dedicated serial queue and renders `CVPixelBuffer` snapshots via `CIContext` and `CGImageDestination`.
- `[ScreenOCR.swift:ScreenOCR.recognize]` - Executes Vision `VNRecognizeTextRequest` (`zh-Hans`, `zh-Hant`, `en-US`) and updates lock-protected static OCR and frame signature caches.
- `[ScreenRecorder.swift:ScreenRecorderManager]` - Schedules `DispatchSourceTimer` auto-stop timers on utility queues and writes `.mp4` recordings to disk via `FileManager.default`.
- `[USBIdentityScreenshot.swift:USBIdentityScreenshot]` - Spawns a child `Process` (`--capture-identity-screenshot`) with an 8-second timeout (`SIGTERM`/`SIGKILL` on timeout) that dynamically loads `MobileDevice.framework` via `dlopen`/`dlsym`, connects to `com.apple.mobile.screenshotr` over USB, and writes PNG screenshot data to a temporary file.
- `[USBValeriaConfigurator.swift:USBValeriaConfigurator]` - Queries IOKit (`IOServiceGetMatchingServices`, `IOCreatePlugInInterfaceForService`, `IOUSBDeviceInterface182`), `SCDynamicStore`, `getifaddrs()`, and `sysctlbyname("kern.bootsessionuuid")`, switches/restores physical USB configurations (`SetConfiguration`), and atomically reads/writes the switch ledger at `~/Library/Application Support/iPhoneUse/usb-valeria-switches.json`.
