# Input

## Overview
Provides iPhone pointer, gesture, scroll, keyboard, and Chinese IME text entry synthesis over Bluetooth HID and the enhanced `poki-native` bridge, dual-track routing (`JevTrackRouter`, `DualTrackInputCoordinator`), post-action visual stillness and OCR verification (`GhosthandPrimitives`), and idle keep-alive management.

## Invariants
- `[ControlTrack.swift:EnhancedInputDriver.normalize]` — Requires `screenWidth > 1` and `screenHeight > 1`; treats coordinates in `0.0...1.0` as fractions, clamps larger pixel coordinates by `x / (screenWidth - 1)` and `y / (screenHeight - 1)` into `0.0...1.0`, and scales to `0...65535`.
- `[ControlTrack.swift:DualTrackInputCoordinator.executeWithFallback]` — In `.auto` mode, attempts the enhanced track only when `currentState != .degradedToStandard` and `enhancedDriver.isAvailable`; on failure, transitions `_state` to `.degradedToStandard` and falls back to `standardInputResolver()`.
- `[ControlTrack.swift:DualTrackInputCoordinator.getAXTree]` — Rejects accessibility tree inspection with `DeviceError` when `mode == .standard` or `!enhancedDriver.isAvailable`.
- `[DeviceInput.swift:DeviceInput.queue]` — Serializes all pointer/keyboard gesture state on per-host queue `"iphone-use.input.<host>"`; drops all outbound reports when `isRetired` is true, and when `!inputIsAllowed()` is true, allows only zero-payload release reports on non-`.absolutePointer` channels.
- `[DeviceInput.swift:DeviceInput.hold]` — Requires finite coordinates in `0...1` and finite `duration` in `0.1...10.0` seconds; `holdDrag` requires finite `holdDuration` in `0.1...10.0` and `dragDuration` in `0.016...10.0`; `scroll` requires `ticks` in `1...1000` and wraps horizontal scrolls (`.left`, `.right`) with keyboard Shift modifier `0x02`; `key(_:modifiers:)` rejects `"mute"` with `InputError.muteKeyRequiresMuteCommand`.
- `[GhosthandPrimitives.swift:PostActionOptions.init]` — Requires `timeoutMs` in `1...60_000`, non-whitespace `waitText` when present, `screenshotFormat` in `png`/`jpeg`/`jpg`, and forces `settle = true` whenever `waitText != nil`, `includeScreenshot`, or `includeScreentext` is enabled.
- `[GhosthandPrimitives.swift:GhosthandDevicePrimitives.unlock]` — Requires non-empty printable US-ASCII (`0x20...0x7E`) `passcode`, enters the passcode at most once, and throws `GhosthandError.unlockFailed` (`422`) without retrying if the device remains locked.
- `[GhosthandPrimitives.swift:GhosthandDevicePrimitives.setMuted]` — Sends consumer mute (`0x00E2`) at most twice and throws `GhosthandError.muteUnconfirmed` (`502`) if USB ringer state is unavailable or remains mismatched.
- `[GhosthandPrimitives.swift:IdleKeepAliveController.evaluateTick]` — Emits a keep-alive control tap only when `hasUSBFrame && !isLocked && isBluetoothReady` and `now - max(lastInputUptime, lastKeepAlive) >= idleInterval`.
- `[KeyboardMap.swift:KeyboardMap.keyboardText]` — Preflights the full input string: Han character runs must transliterate via ICU Latin/stripCombiningMarks (`ü` -> `v`) into non-empty lowercase `a-z` Pinyin followed by a space, and all non-Han characters must map to a valid `KeyboardMap.stroke`.
- `[TextEntry.swift:TypeTextRequest.perform]` — Writes `.clipboard` payloads before `clear_before`, Chinese IME switching (`Control+Space`), or any `.key`/`.text` steps.

## Side Effects
- `[ControlTrack.swift:EnhancedBridgeProcess.run]` — Spawns the external `poki-native` child `Process` (`--udid <udid>`), writes JSON requests to `stdin`, waits on a `DispatchSemaphore` up to `timeout` (terminating the subprocess on timeout), and reads `stdout`/`stderr`.
- `[DeviceInput.swift:DeviceInput.send]` — Dispatches Bluetooth LE HID reports (`.keyboard`, `.relativeMouse`, `.absolutePointer`, `.consumer`) through `HIDPeripheral.shared.send` on the per-host serial `DispatchQueue` and sleeps between gesture steps.
- `[GhosthandPrimitives.swift:IdleKeepAliveController.start]` — Schedules a repeating 1.0-second `DispatchSourceTimer` that invokes `sendControlTap()` on idle unlocked devices.
- `[JevTrackRouter.swift:JevTrackRouter.decide]` — Reads `JEV_API_URL`, `TYPESAFE_API_KEY`, `JEV_API_KEY`, and `JEV_MODEL` from the environment and sends a synchronous HTTP `POST` request via `URLSession.shared` when an API key is configured.
- `[TextEntry.swift:TextEntry.writeClipboard]` — Mutates `NSPasteboard.general` on the main thread (`DispatchQueue.main.sync` when called off-main).
