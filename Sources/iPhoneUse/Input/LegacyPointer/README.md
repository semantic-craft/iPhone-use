# LegacyPointer

## Overview
Provides relative Bluetooth HID pointer motion observation, automatic first-use pointer calibration over USB screen frames, movement planning, and persistent calibration profile storage for legacy relative-pointer fallback paths.

## Interface
- `[AutomaticPointerCalibration.swift:AutomaticPointerCalibration]` — `final class AutomaticPointerCalibration` with `typealias Frame = PointerMotionObservation.Frame`, `init(host: UUID, screenID: String, width: Int, height: Int, send: @escaping (Int, Int) throws -> Void, capture: @escaping () throws -> Frame, progress: @escaping (Int) -> Void = { _ in })`, and `func measure() throws -> RelativePointerCalibration`.
- `[PointerMotionObservation.swift:PointerMotionObservation]` — `enum PointerMotionObservation` with nested `struct Frame` (`width: Int`, `height: Int`, `pixels: [UInt8]`, `var isValid: Bool`), `struct Motion` (`from: CGPoint`, `to: CGPoint`, `var delta: CGPoint`), `static func changedPixels(_ a: Frame, _ b: Frame) -> Int?`, `static func closedRectangleOrigin(_ frames: [Frame]) -> CGPoint?`, and `static func motion(from a: Frame, to b: Frame, direction: CGPoint) -> Motion?`.
- `[RelativePointerCalibration.swift:RelativePointerCalibration]` — `struct RelativePointerCalibration: Codable` storing `host: UUID`, `screenID: String?`, `screenWidth: Int`, `screenHeight: Int`, `reportInterval: Double`, `distances: [Double]`, `vectorModel: VectorModel?`, nested `enum VectorModel: String, Codable` (`.radialQuantized`), nested `struct Movement` (`dx: Int`, `dy: Int`), `func validate() throws`, `func matches(_ size: CGSize) -> Bool`, `func plan(from start: CGPoint, to target: CGPoint) -> (reports: [Movement], position: CGPoint)`, `func trackingStep(from start: CGPoint, to target: CGPoint, after lastMove: Movement?) -> (report: Movement, position: CGPoint)?`, and `var homingReports: [Movement]`.
- `[RelativePointerCalibration+Storage.swift:PairingProbeCalibration]` — `enum PairingProbeCalibration` with cases `.calibrated(RelativePointerCalibration)`, `.absolute`, and `.unavailable`.
- `[RelativePointerCalibration+Storage.swift:RelativePointerCalibration]` — Storage extension providing `struct StorageSnapshot: Equatable`, `static func fileURL(host: UUID) -> URL`, `static func screenFileURL(screenID: String, directory: URL) -> URL`, `static func storageSnapshot(host: UUID, screenID: String, directory: URL? = nil) throws -> StorageSnapshot`, `func saveVerified(directory: URL? = nil, ifUnchanged expected: StorageSnapshot? = nil) throws`, `static func markRequired(screenID: String, directory: URL? = nil) throws`, `static func clearRequirementAfterAbsoluteProof(screenID: String, directory: URL? = nil) throws`, `static func load(host: UUID, screenSize: CGSize?, screenID: String? = nil) -> Self?`, `static func load(host: UUID, screenSize: CGSize?, screenID: String? = nil, directory: URL) -> Self?`, `static func requiresCalibration(host: UUID, screenID: String?) -> Bool`, `static func requiresCalibration(host: UUID, screenID: String?, directory: URL) -> Bool`, `static func isBoundToDifferentScreen(host: UUID, screenID: String, directory: URL? = nil) -> Bool`, `static func boundScreenID(host: UUID, directory: URL? = nil) -> String?`, `static func isBoundToScreen(host: UUID, screenID: String, directory: URL? = nil) -> Bool`, `static func pairingProbeCalibration(host: UUID, screenID: String, directory: URL? = nil) -> PairingProbeCalibration`, `static func probeInputCalibration(host: UUID, screenID: String?, directory: URL? = nil) -> (calibration: Self?, required: Bool)`, `static func loadMatchingScreen(host: UUID, screenSize: CGSize?, screenID: String? = nil) -> Self?`, and `static func loadMatchingScreen(host: UUID, screenSize: CGSize?, screenID: String? = nil, directory: URL) -> Self?`.

## Invariants
- `[AutomaticPointerCalibration.swift:measure()]` — Requires `(200...4096).contains(width)`, `(300...4096).contains(height)`, and `!screenID.isEmpty`; requires initial pointer sample `> 0`, anchor homing within `256` reports per axis, sampling origin within `x in (55, width * 0.55)` and `y in (55, height - 180)`, strictly increasing finite horizontal distances for counts `1...32`, vertical counts `[4, 16, 32]` matching horizontal distances within `max(0.5, distances[count] * 0.02)`, and landing verification within `3` pixels across target fractions `[(0.3, 0.4), (0.65, 0.6), (0.4, 0.5)]`.
- `[AutomaticPointerCalibration.swift:sample(count:axis:reports:)]` — Requires `changedPixels(before, returned) <= 256`, `distance(forward.from, reverse.to) <= 2`, `distance(forward.to, reverse.from) <= 1`, and cross-axis drift `abs(forward.delta) <= 1`.
- `[PointerMotionObservation.swift:Frame.isValid]` — Requires `width` in `1...4096`, `height` in `1...4096`, and `pixels.count == width * height`.
- `[PointerMotionObservation.swift:closedRectangleOrigin(_:)]` — Requires `5` frames forming a 4-edge axis-aligned closed rectangle (`right`, `down`, `left`, `up`) with positive edge projection, cross-axis drift `<= 2` pixels, and corner arrival-to-departure distance `<= 2` pixels.
- `[PointerMotionObservation.swift:motion(from:to:direction:)]` — Requires valid equal-sized frames, finite non-zero `direction`, connected blob area `<= 10000`, accumulated fragment noise `<= 256` pixels, unclipped blob bounds (`minX > 1`, `minY > 1`, `maxX < width - 2`, `maxY < height - 2`), and exactly `2` circular pointer blobs (`8...100` px, `abs(w - h) <= 2`, fill ratio `>= 0.6`, size diff `<= 1`, area ratio `>= 0.85`, and non-intersecting 3-pixel expanded bounding boxes).
- `[RelativePointerCalibration.swift:validate()]` — Requires `screenWidth` and `screenHeight` in `1...16384`, finite `reportInterval` in `0.01...0.1`, `distances.count` in `2...128`, `distances.first == 0`, strictly increasing finite distances with `distances[1] >= 0.05`, and `ceil(screenWidth / distances.last!) + ceil(screenHeight / distances.last!) <= 512`.
- `[RelativePointerCalibration.swift:plan(from:to:)]` — Clamps targets to `0...Double(screenWidth - 1)` and `0...Double(screenHeight - 1)`, bounds planning to `4096` steps per axis, stops when `abs(remaining) < distances[1] / 2`, and emits only moves that strictly reduce remaining axis error.
- `[RelativePointerCalibration.swift:trackingStep(from:to:after:)]` — Requires remaining error `> distances[1] / 2` (`tolerance`), bounds per-axis overshoot to `tolerance`, and in `.radialQuantized` mode requires `0 < hypot(x, y) <= Double(maxCount)` without extrapolating beyond `distances.count - 1`.
- `[RelativePointerCalibration+Storage.swift:saveVerified(directory:)]` — Requires `validate()` to pass and a non-empty `screenID`; atomically writes both `by-screen/<hex>.json` and `<host>.json` and rolls back both files if either write fails.
- `[RelativePointerCalibration+Storage.swift:load(host:screenSize:screenID:directory:)]` — Requires decoded profiles to pass `validate()`, `result.host == host`, and `screenID == nil || result.screenID == nil || result.screenID == screenID`.

## Side Effects
- `[AutomaticPointerCalibration.swift:measure()]` — Invokes the injected `send(dx, dy)` closure to emit relative Bluetooth HID pointer reports, calls `capture()` to read USB video frames, invokes `progress(count)`, and mutates internal `position`.
- `[RelativePointerCalibration+Storage.swift:saveVerified(directory:)]` — Creates directories and atomically writes calibration JSON files under `~/Library/Application Support/iPhoneUse/pointer-calibration/` (`<host>.json` and `by-screen/<hex>.json`), restoring or removing files on rollback.
- `[RelativePointerCalibration+Storage.swift:markRequired(screenID:directory:)]` — Creates the `required/` subdirectory and atomically writes a calibration requirement marker JSON file on disk.
- `[RelativePointerCalibration+Storage.swift:clearRequirementAfterAbsoluteProof(screenID:directory:)]` — Deletes the requirement marker JSON file for `screenID` from disk via `FileManager`.
- `[RelativePointerCalibration+Storage.swift:load(host:screenSize:screenID:directory:)]` — Reads calibration JSON files from disk and routes valid UDID-bound profiles to `host`.
