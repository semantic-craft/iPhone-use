# Devices

## Overview
Manages physical iPhone discovery, deterministic device addressing, USB-to-Bluetooth identity verification and pairing recovery, lock-screen state monitoring, setup readiness evaluation, relative pointer calibration jobs, and cross-process SQLite device leases.

## Interface

- `[DeviceAddressing.swift:DeviceCandidate]` — `struct DeviceCandidate: Equatable` holding `id: String` and `name: String`.
- `[DeviceAddressing.swift:DeviceAddressingError]` — `enum DeviceAddressingError: Error, Equatable` with `.noDevicesConnected`, `.multipleDevicesConnected(count: Int)`, `.noMatch(query: String)`, and `.ambiguousMatch(query: String, count: Int)`.
- `[DeviceAddressing.swift:DeviceAddressing]` — `enum DeviceAddressing` providing `static func resolve(_ rawSelector: String?, from candidates: [DeviceCandidate]) -> Result<DeviceCandidate, DeviceAddressingError>`.

## Invariants
- `[DeviceAddressing.swift:DeviceAddressing.resolve]` — `.defaultDevice` succeeds only when `candidates.count == 1`; `.query` matches by strict case-insensitive tier precedence (exact ID -> exact name -> ID prefix) and returns `.ambiguousMatch` if the matching tier has `count != 1`.
- `[DeviceAddressing.swift:RuntimeEnvironment.isLiveHardwareAllowed]` — Returns `false` when `IPHONE_USE_HERMETIC_TEST` is `1`/`true`/`yes`, when any `XCTest*` environment variable is present, or when a non-empty `IPHONE_USE_STATE_DIR` is outside `~/Library/Logs/iPhoneUse` and `~/Library/Application Support/iPhoneUse`.
- `[DeviceLockMonitor.swift:DeviceLockObservations]` — Requires `2` consecutive fresh `.suspected` observations (`< 8` seconds apart) for the same `captureID` before reporting `.suspected`, and expires observations older than `8` seconds to `.unknown`; frames older than `5` seconds report `.paused`.
- `[DevicePairing.swift:PointerScreenMatcher.matchesAbsoluteRoundTrip]` — Requires `4` frames of `90 * 195` bytes, `3` valid targets (`0.05...0.95`, pairwise distance `>= 20`, x-span `>= 30`, y-span `>= 35`), pixel delta `> 12` within a 15x15 window (`3...150` changed pixels, arrival/departure intersection `>= 75%`), `backgroundChanges <= 2`, `returnChanges <= 2`, and centroid within `3` pixels of target.
- `[RelativePointerScreenMatcher.swift:RelativePointerScreenMatcher.matches]` — Requires `5` frames of `180 * 320` bytes forming a closed 4-edge axis-aligned rectangle returning to frame 0 at frame 4.
- `[DeviceRegistry.swift:DeviceRegistry.lock]` — `inputLock` is always acquired before `lock` when both locks are held (`automaticallyCalibrate`) so `DeviceInput` construction cannot deadlock with `lock`; `matchQueue` preconditions guard all probe state mutations.
- `[DeviceRegistry.swift:DeviceRegistry.buildDevices]` — Assigns a non-nil `host` to a `Device` only when `ScreenCaptureManager.shared.isCurrent(screen)` is `true`, the host has an active BLE `session`, and `verifiedAssociations` contains `Association(screen: screen.associationIdentity, host: host, session: session)`.
- `[DeviceRegistry.swift:DeviceRegistry.store]` — Enforces a 1-to-1 host-to-screen mapping by removing any prior pairing to `host`, invalidating replaced `verifiedAssociations`, verifying `expectedPairings` if provided, and requiring `preparedScreens` evidence when `motionVerified == true`.
- `[LeaseStore.swift:LeaseID.init?(rawValue:)]` — Enforces `rawValue > 0`; `LeaseID.parse` rejects booleans, non-integer numbers, empty strings, and non-positive suffixes.
- `[LeaseStore.swift:LeaseStore.acquire]` — Requires non-empty trimmed `reason` and finite `idleTimeoutSeconds` in `1...86_400`; `wait` additionally requires finite `waitSeconds` in `0.05...3_600`; `initializeSchema` enforces `UNIQUE` on `lease.screen_capture_id` (at most one active lease per device) and evicts expired leases where `(last_used_at + idle_timeout_s) <= now` inside a `BEGIN IMMEDIATE TRANSACTION`.
- `[SetupReadiness.swift:SetupReadiness.classifyStep]` — Evaluates setup steps in strict priority order: `.trust` -> `.usbUnreadable` (`captureError`) -> `.unlock` (`!hasFrame` or `.suspected`) -> `.usbUnreadable` (`.paused`) -> `.bluetoothUnavailable` -> `.pair` -> `.connecting` -> `.ready`.

## Side Effects
- `[DeviceLockMonitor.swift:DeviceLockMonitor.start]` — Starts a repeating 2-second `DispatchSourceTimer` on queue `"iphone-use.device-lock-monitor"` that reads frames from `ScreenCaptureManager.shared` and invokes `LockScreenRecognition.read`.
- `[DevicePairing.swift:DevicePairingStore]` — Creates `~/Library/Application Support/iPhoneUse` and reads/writes `pairings.json` on disk.
- `[DeviceRegistry.swift:DeviceRegistry.start]` — Loads saved pairings from disk, registers `ScreenCaptureManager.shared.onScreensChanged` and `HIDPeripheral.shared.onHostsChanged` callbacks, starts `DeviceLockMonitor.shared`, and schedules BLE matching on `matchQueue`.
- `[DeviceRegistry.swift:DeviceRegistry.syncBluetoothForCurrentScreens]` — Updates `HIDPeripheral.shared.setUSBScreenDemand`, triggers `HIDPeripheral.shared.reconnectKnownHosts`, and enables AssistiveTouch over USB via `StateDirUSBSystemProvider.shared.setAssistiveTouch(deviceID:enabled: true)` when `RuntimeEnvironment.isLiveHardwareAllowed()` is true.
- `[DeviceRegistry.swift:DeviceRegistry.motionEvidence]` — Emits physical BLE HID pointer probe reports (`input.pairingProbe`, `input.relativePairingProbe`), captures USB screen thumbnails, and updates calibration markers and profiles on disk (`RelativePointerCalibration.clearRequirementAfterAbsoluteProof`, `markRequired`, `saveVerified`).
- `[LeaseStore.swift:LeaseStore]` — Creates `<stateDir>/state.db` and `<stateDir>/state.db.lock`, acquires cross-process `flock(LOCK_EX)` locks, executes SQLite WAL transactions across `lease_counter`, `lease`, and `lease_waiter` tables, and stops active screen recordings via `ScreenRecorderManager.shared.stopIfActive(forLease:stoppedBy: .leaseEnded)` when leases expire, are replaced, or are released.
- `[SetupReadiness.swift:SetupReadiness.liveInputs]` — Queries `AVCaptureDevice.authorizationStatus(for: .video)`, `HIDPeripheral.shared`, `USBValeriaConfigurator.currentIOSUSBTopology()`, `DeviceRegistry.shared`, `DevicePairingStore`, `LeaseStore`, `ScreenCaptureManager.shared`, and `MobileDeviceLockdownBridge.attachedDevices()`.
