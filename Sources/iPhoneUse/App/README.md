# App

## Overview
Manages the macOS application lifecycle, run-mode resolution and persistence (`desktop` vs. `residentQuiet`), application menu bar, signal/power observers, and idle screen-capture suspension in resident quiet mode.

## Interface
- `[AppRunMode.swift:AppRunMode]` — Run-mode enum (`desktop`, `residentQuiet`) with CLI flags `--resident-quiet` (`[AppRunMode.swift:AppRunMode.residentQuietFlag]`) and `--desktop` (`[AppRunMode.swift:AppRunMode.desktopFlag]`), `parse(_:)` (`[AppRunMode.swift:AppRunMode.parse]`), and `resolve(arguments:environment:persistedRawValue:)` (`[AppRunMode.swift:AppRunMode.resolve]`).
- `[AppRunMode.swift:AppRunModeStore]` — Thread-safe run-mode store with `shared` singleton (`[AppRunMode.swift:AppRunModeStore.shared]`), notification `AppRunModeStore.didChange` (`[AppRunMode.swift:AppRunModeStore.didChangeNotification]`), UserDefaults/environment key `IPHONE_USE_RUN_MODE` (`[AppRunMode.swift:AppRunModeStore.defaultsKey]`, `[AppRunMode.swift:AppRunModeStore.environmentKey]`), `mode` getter (`[AppRunMode.swift:AppRunModeStore.mode]`), `init(defaults:arguments:environment:persistHook:)` (`[AppRunMode.swift:AppRunModeStore.init]`), and `set(_:)` (`[AppRunMode.swift:AppRunModeStore.set]`).
- `[Application.swift:log]` — Writes an ISO8601-timestamped log line to standard error.
- `[Application.swift:AppDelegate]` — `NSApplicationDelegate` managing the application, window, language, and resident-quiet-mode menus, plus lifecycle callbacks `applicationDidFinishLaunching(_:)` (`[Application.swift:AppDelegate.applicationDidFinishLaunching]`), `applicationShouldTerminateAfterLastWindowClosed(_:)` (`[Application.swift:AppDelegate.applicationShouldTerminateAfterLastWindowClosed]`), `applicationShouldHandleReopen(_:hasVisibleWindows:)` (`[Application.swift:AppDelegate.applicationShouldHandleReopen]`), and `applicationWillTerminate(_:)` (`[Application.swift:AppDelegate.applicationWillTerminate]`).
- `[Application.swift:Application]` — Application bootstrap namespace providing `shutdownWaitTimeout = 3.0` (`[Application.swift:Application.shutdownWaitTimeout]`), `terminationExitCode(for:)` (`[Application.swift:Application.terminationExitCode]`), and `run()` (`[Application.swift:Application.run]`, reading `IPHONE_USE_PORT` with default `7390`).
- `[QuietModeActivityController.swift:QuietModeActivityController]` — Resident-quiet idle capture controller with `shared` singleton (`[QuietModeActivityController.swift:QuietModeActivityController.shared]`), `init(environment:mode:now:suspendCapture:checkIdleUnplug:resumeCapture:)` (`[QuietModeActivityController.swift:QuietModeActivityController.init]`, reading `IPHONE_USE_IDLE_TIMEOUT` with default `60` seconds), `start()` (`[QuietModeActivityController.swift:QuietModeActivityController.start]`), `stop()` (`[QuietModeActivityController.swift:QuietModeActivityController.stop]`), `modeChanged()` (`[QuietModeActivityController.swift:QuietModeActivityController.modeChanged]`), `setOpenWindows(_:)` (`[QuietModeActivityController.swift:QuietModeActivityController.setOpenWindows]`), `requestStarted()` (`[QuietModeActivityController.swift:QuietModeActivityController.requestStarted]`), `requestFinished()` (`[QuietModeActivityController.swift:QuietModeActivityController.requestFinished]`), `checkIdle()` (`[QuietModeActivityController.swift:QuietModeActivityController.checkIdle]`), `isSuspended` (`[QuietModeActivityController.swift:QuietModeActivityController.isSuspended]`), and `isWithinWakeGraceWindow` (`[QuietModeActivityController.swift:QuietModeActivityController.isWithinWakeGraceWindow]`).

## Invariants
- `[AppRunMode.swift:AppRunMode.resolve]` prioritizes CLI flags (`--resident-quiet`, `--desktop`; last flag wins) over the `IPHONE_USE_RUN_MODE` environment variable, which overrides the persisted `UserDefaults` value; unset or unrecognized inputs default to `.desktop`.
- `[AppRunMode.swift:AppRunModeStore.init]` and `[AppRunMode.swift:AppRunModeStore.set]` keep startup CLI/environment overrides in memory without writing to `UserDefaults`; only explicit `set(_:)` calls persist to `UserDefaults`, and `didChangeNotification` is posted outside the lock only when `current != mode`.
- `[Application.swift:AppDelegate.applicationShouldTerminateAfterLastWindowClosed]` always returns `false` so closing the last window never terminates the daemon/app.
- `[Application.swift:Application.terminationExitCode]` returns `0` when `ScreenCaptureStopResult.isClean` is `true`, and `1` otherwise.
- `[Application.swift:Application.run]` retains `appDelegate`, `HTTPServer`, `signalSources`, and `powerObservers` across `app.run()` via `withExtendedLifetime` because `NSApplication.delegate` is a weak reference.
- `[QuietModeActivityController.swift:QuietModeActivityController.start]`, `[QuietModeActivityController.swift:QuietModeActivityController.stop]`, and `[QuietModeActivityController.swift:QuietModeActivityController.setOpenWindows]` enforce main-thread execution via `precondition(Thread.isMainThread)`; cross-thread entrypoints (`requestStarted`, `requestFinished`, `isSuspended`, `isWithinWakeGraceWindow`) synchronize onto `DispatchQueue.main` via `onMain` after checking `runningLock`.
- `[QuietModeActivityController.swift:QuietModeActivityController.init]` requires `IPHONE_USE_IDLE_TIMEOUT` to parse as a finite number `> 0` (otherwise defaulting to `60` seconds), and `[QuietModeActivityController.swift:QuietModeActivityController.isWithinWakeGraceWindow]` maintains a `6.0`-second grace window after resume.
- `[QuietModeActivityController.swift:QuietModeActivityController.checkIdle]` suspends capture only when `mode() == .residentQuiet`, `!openWindows`, `activeRequests == 0`, and elapsed time since `lastActivity` is `>= timeout`; `[QuietModeActivityController.swift:QuietModeActivityController.requestFinished]` clamps `activeRequests` so it never drops below `0`.

## Side Effects
- `[Application.swift:log]` writes formatted log lines to `FileHandle.standardError`.
- `[AppRunMode.swift:AppRunModeStore.set]` writes `mode.rawValue` to `UserDefaults` under `IPHONE_USE_RUN_MODE`, invokes `persistHook`, and posts `AppRunModeStore.didChangeNotification` on `NotificationCenter.default`.
- `[Application.swift:Application.run]` configures `NSApplication.shared` (`.regular` activation policy and `AppIcon.icns`), starts `DeviceRegistry.shared`, `HIDPeripheral.shared`, `ScreenCaptureManager.shared`, and `HTTPServer` on `127.0.0.1:port` (calling `exit(1)` if starting the server fails), registers `NSWorkspace` sleep/wake/screen power observers, and installs `SIGINT`/`SIGTERM` `DispatchSource` handlers that stop subsystems and call `exit(_:)`.
- `[Application.swift:AppDelegate.applicationDidFinishLaunching]` installs `NSApp.mainMenu` and `NSApp.windowsMenu`, starts `QuietModeActivityController.shared`, `IdleKeepAliveController.shared`, and `ControlWindowCoordinator`, activates `NSApp` in `.desktop` mode, and registers `NotificationCenter` observers for language and run-mode changes.
- `[Application.swift:AppDelegate.applicationWillTerminate]` removes observers and stops `QuietModeActivityController`, `IdleKeepAliveController`, `ScreenRecorderManager`, `ControlWindowCoordinator`, `ScreenCaptureManager` (waiting up to `3.0` seconds), and `HIDPeripheral`.
- `[QuietModeActivityController.swift:QuietModeActivityController.start]` and `[QuietModeActivityController.swift:QuietModeActivityController.stop]` schedule/invalidate a repeating `RunLoop.main` (`.common` mode) `Timer`, register/remove the `AppRunModeStore.didChangeNotification` observer, and update `HIDPeripheral.shared.setResidentQuietDemand(_:)`.
- `[QuietModeActivityController.swift:QuietModeActivityController.checkIdle]` and `[QuietModeActivityController.swift:QuietModeActivityController.wake]` suspend capture via `ScreenCaptureManager.shared.suspendForIdle()`, clear unplugged USB demand via `clearIdleUSBDemandIfUnplugged()`, and resume capture via `DeviceRegistry.shared.prewakeBluetoothForIdleResume()` and `ScreenCaptureManager.shared.start()`.
